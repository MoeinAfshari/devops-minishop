# Database Persistence

- Why shouldn't the database be only on the writable layer? The database shouldn't be only on the writable layer because data written to the writable container layer doesn't persist when the container is destroyed.
- What's PostgreSQL Data Directory? For the PostgreSQL 16 Docker image, the default data directory inside the container is `/var/lib/postgresql/data`.
- What's Docker Volume? Docker Volumes provide persistent storage for data generated by containers. A volume is mounted into the container and remains available even when the container is stopped, removed, or recreated, as long as the volume itself is not deleted. 
- What's the difference between container deletion vs data deletion? `docker rm -f container_name` deletes the container and its writable layer. Data stored in a mounted Docker Volume remains available. `docker volume rm volume_name` deletes the volume and the data stored in it. A deleted container can be recreated and reconnected to the same volume, but deleting the volume removes the persistent data stored there.
