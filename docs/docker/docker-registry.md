# Docker Registry

## What's Registry?

Docker Registry is a centralized storage and distributed system for collection and managing Docker images.

Like:
```Bash
Docker Hub
GitHub Container Registry
Private Registry
```

## What's Repository?

A Docker Hub repository is a collection of container images, enabling you to store, manage, and share Docker images publicly or privately.

Like:
```Bash
moein/minishop-backend
```

## What's Docker Hub?

Docker hub is the largest container registry that built for developers and open source contributors to find, use and share their container images.

## Public vs Private Repositories

Everyone has access to public images, they just need to have the tag for that image while only the defined users for an image with a specific username and password are allowed to access private images.
