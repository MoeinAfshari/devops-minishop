## Day 44 Challenges

### Challenge 1 - Environment validation

Only three values, `development`, `staging` and `production` must be valid.
Delivery: The complete Variable block, along with two Plan commands to test for a valid value and an invalid value.
Criteria: The type, default value, and validation rule must be correct.

#### Answer

Add this in the end of `variables.tf` file:
```hcl
variable "environment_name" {
  description = "Name of the environment lab."
  type        = string
  default     = "development"

  validation {
    condition = contains(
      ["development", "staging", "production"],
      var.environment_name
    )

    error_message = "environment_name must be development, staging, or production."
  }
}
```
Correct:
```Bash
terraform fmt
terraform validate

terraform plan -var="environment_name=staging"
```
Incorrect:
```Bash
terraform plan -var="environment_name=moein"
```

### Challenge 2 - Using input file

The default value is `development`; for testing we want to use the `staging` value.
Deliverables: The appropriate input file and Plan command, without changing the default value in the code.
Criteria: Be able to explain why the file is or is not automatically loaded.

#### Answer

Add this in the `dev.tfvars` file:
```hcl
environment_name = "staging"
```
Then:
```Bash
terraform plan -var-file="dev.tfvars"
```
This file needs to `-var-file` to apply and doesn't load automatically. For automatic loading, we need to use `.auto.tfvars` extension or `terraform.tfvars` file.
